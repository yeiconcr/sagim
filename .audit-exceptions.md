# Security Audit Exceptions

Este documento lista las vulnerabilidades conocidas que se han evaluado y aceptado temporalmente.

## xlsx (SheetJS)

**Severidad:** High  
**CVE:** GHSA-4r6h-8v6p-xvw6, GHSA-5pgg-2g8v-p9x9  
**Descripción:** Prototype Pollution y ReDoS  
**Estado:** No hay fix disponible  

**Mitigación:**
- La biblioteca se usa solo para exportar datos a Excel (output)
- No se procesan archivos Excel de fuentes no confiables (input)
- El riesgo es bajo porque solo generamos archivos, no los parseamos

**Plan:**
- Monitorear actualizaciones de xlsx
- Considerar migrar a `exceljs` si se requiere procesar archivos de entrada
- Revisar trimestralmente
